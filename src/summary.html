Top creators

# group per creator, then sort by total impressions
creator_summary <- videos %>%
  group_by(creator_id) %>%
  summarise(
    videos_n          = n(),
    impressions_total = sum(impressions_n, na.rm = TRUE),
    watch_rate_avg    = mean(watch_rate, na.rm = TRUE)
  ) %>%
  arrange(desc(impressions_total))

Short videos vs long videos

# make a group variable, then compare the two groups
length_groups <- videos %>%
  mutate(length_group = ifelse(video_length_sec < 30, "short", "long")) %>%
  group_by(length_group) %>%
  summarise(
    videos_n       = n(),
    watch_rate_avg = mean(watch_rate, na.rm = TRUE),
    watch_share_avg = mean(avg_watch_share, na.rm = TRUE)
  )

Conclusion

  • Most videos in the dataset are short.
  • Short videos have a higher average watch share: people finish them more often.
  • Long videos still get watched, but viewers drop out before the end.
