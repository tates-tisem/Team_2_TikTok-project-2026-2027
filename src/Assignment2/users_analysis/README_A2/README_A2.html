By Tuana Ates

Goal

The TikTok research has produced a large table of platform users. Each row is one user, with their profile identifiers and a set of behavioural traits (how often they tend to log in, how quickly they get bored, how many videos they usually watch, and their taste for each content category). It is time to inspect and analyze this user data:

  1. look at how the traits are distributed
  2. check whether values are missing or implausible
  3. explore how different types of users compare.
