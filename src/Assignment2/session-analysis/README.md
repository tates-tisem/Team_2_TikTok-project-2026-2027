# Session Analysis

This folder contains the session analysis.

## How to run

Open a terminal in the project root and run:

```bash
make -C src/session-analysis
```

Or, if you are already in the `src/session-analysis` folder, run:

```bash
make
```

To remove the generated plots, open a terminal in the `src/session-analysis` folder and run:

```bash
make clean
```
